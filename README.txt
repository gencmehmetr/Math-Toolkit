# Math Toolkit 

Bu proje, Python öğrenme sürecimde geliştirdiğim basit bir uygulamadır.

### Projenin İçindeki Modüller:
1. Dört İşlem
2. Daire Alanı ve Çevresi
3. Diskriminant Hesaplama
4. Sayı Durumu (Pozitif/Negatif/Sıfır)
5. Parçalı Fonksiyon Hesaplayıcısı

### Nasıl Çalıştırılır?
Projeyi bilgisayarınıza indirip terminalde şu komutu çalıştırın:
python main.py
